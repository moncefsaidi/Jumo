Jumo PWA - نسخة أولية

محتويات المشروع:
- واجهة تسجيل الدخول عبر Supabase Auth
- لوحة أولية لعرض أقسام المخزون والإنتاج والمبيعات والمصاريف والأجور
- إضافة مواد إلى inventory_items
- manifest و service worker لتثبيت PWA

مهم:
1) لا ترفع هذا المشروع على استضافة عامة قبل مراجعة سياسات RLS.
2) Publishable key مخصص للواجهة، لكن لا تضع أبداً service_role أو secret key في ملفات المتصفح.
3) هذه نسخة أولية؛ نماذج الإنتاج والمبيعات والمصاريف والأجور وواجهة العمال ستُستكمل لاحقاً.
4) الاستضافة المجانية تتطلب نشر الملفات على خدمة تدعم HTTPS مثل GitHub Pages.
